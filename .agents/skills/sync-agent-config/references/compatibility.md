# Compatibility Matrix

This skill assumes `.agents` is canonical and adapts to the target tool instead of forcing dead copies.

## Targets

### Claude

- Agents: native via `.claude/agents/*.md`
- Skills: native via `.claude/skills/*/SKILL.md`
- MCP: project `.mcp.json`
- Notes: requires generated copies because Claude does not natively scan `.agents`

### Cursor

- Agents: no direct equivalent
- Skills: no direct equivalent
- MCP: project `.cursor/mcp.json`
- Notes: use root `AGENTS.md` plus a generated `.cursor/rules/agents-and-skills-index.mdc`

### GitHub Copilot

- Agents: native via `.github/agents/*.agent.md`
- Skills: supports `.agents/skills` directly
- MCP: practical repo-level setup via `.vscode/mcp.json`
- Notes: existing `.github/skills/*` mirrors may be redundant if `.agents/skills` is already present

### OpenCode

- Agents: native via `.opencode/agents/*.md`
- Skills: supports `.agents/skills` directly
- MCP: configured in `opencode.jsonc`
- Notes: prefer a thin config file instead of duplicating skills

### Codex

- Agents: no repo-local mirror generated by default
- Skills: no repo-local mirror generated by default
- MCP: no repo-local file generated by default
- Notes: rely on root `AGENTS.md` and canonical `.agents`; report support as degraded rather than inventing a private format

### Factory Droid

- Agents: native equivalent via `.factory/droids/*.md`
- Skills: native via `.factory/skills/*`
- MCP: project `.factory/mcp.json`
- Notes: requires generated copies because Droid uses `.factory/*`

## Safety model

- Generated Markdown and rule files carry an HTML managed header.
- Generated JSON and JSONC files carry a top-level `x-sync-agent-config` metadata key.
- The sync script overwrites only managed files it created earlier.
- Unmanaged files are reported as conflicts and left unchanged.

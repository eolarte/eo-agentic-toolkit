# Idea Artifact Map

Idea artifacts live under `docs/ideas/<idea-name>/`.

Core sequence:

1. `01-idea-brief.md` - initial problem, users, outcomes, candidate requirements, assumptions, scope, and open questions
2. `02-requirements-candidates.md` - optional draft behavioral requirements
3. `04-research.md` - evidence, options, trade-offs, recommendation, and implications
4. `05-option-comparison.md` - optional side-by-side option analysis
5. `06-recommendation.md` - optional standalone recommendation
6. `07-clarification-interview.md` - decisions, refined requirements, updated assumptions, and readiness
7. `08-idea-presentation.md` - signoff pitch and user decision
8. `09-handoff-to-spec.md` - approved scope for `spec-prd-writing`

Brainstorm artifacts live under `docs/ideas/<idea-name>/brainstorm/`:

1. `01-free-ideation.md`
2. `02-discussion.md`
3. `03-concept-[a/b/c].md`
4. `04-team-vote.md`
5. `05-summary.md`

Read the artifacts that exist and matter for the current skill. Do not require optional files before proceeding.
